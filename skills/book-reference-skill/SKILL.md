# Book-referenced coursework

Use the project root as the base directory. Course guidelines live in `reference/guidelines/`, assigned textbooks and chapter extracts in `reference/`, and new deliverables go in `output/` unless the user supplies another destination.

1. Start with the user's requested artifact and read the applicable guideline PDF, including its practical requirements and bibliography. Find the topic, chapter or subsection, and reference number. Resolve the reference number to a title, author, and edition. Ask which guide applies if several guides conflict and the request does not resolve the choice.
2. Find the cited book or chapter extract in `reference/`. Verify its identity and section coverage from the document itself. Use the contents, headings, or printed page numbers to locate the assigned material. When text extraction misses scanned pages, tables, or diagrams, render those pages and inspect them visually.
3. Before generating the affected artifact, confirm that the assigned sections were read. If a required book, edition, or section is missing or unreadable, tell the user exactly what to place in `reference/` and pause that artifact. Apply the same check to existing artifacts being revised.
4. Apply the assigned method and notation to the user's data. Use teacher-supplied numerical assumptions for the assignment and label any other assumptions. Cite the guideline topic and book edition and section in the artifact, caption, or accompanying notes. Verify calculations and figure labels against the sources before delivering.

For Foresight, the course guide's bibliography maps [1] to Pressman and Maxim (9th ed.), [2] to Aggarwal and Singh (3rd ed.), and [3] to Jalote (3rd ed.). Check the guide's topic-to-section table for each request.
